# Changelog

## 0.1.0

First public release.

- Language: shapes, classes with typed members, Python-style inheritance, relations as words, multiplicities, variables, stereotypes, containers and an optional layout block.
- Compiler with diagnostics, suggestions and fixes.
- Printer and formatter with a stable canonical style.
- Mermaid and PlantUML output.
- `structa` command line: `check`, `fmt`, `compile`, `lsp`.
- Language server: diagnostics, completion, hover, definition, references, rename, symbols, formatting.
